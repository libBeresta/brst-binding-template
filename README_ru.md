# brst-binding-template

Репозиторий для языковой привязки библиотеки `libBeresta`, свободной,
открытой, кросс-платформенная библиотеки для генерации PDF-файлов.

## Что в этом репозитории

Здесь представлен шаблон кода, необходимый для начала работы
над языковой привязкой.

Для обеспечения единообразия между языковыми привязками, в этом
репозитории представлен образец файла `CMakeLists.txt`, содержащих
обращение к библиотеке `libBeresta`, а также описываются
три сборочные цели:

| Цель      | Описание                                        |
|:----------|:------------------------------------------------|
| `binding` | Подготовка (генерация) файлов языковой привязки |
| `check`   | Проверка работоспособности привязки             |
| `bundle`  | Сборка файла для выпуска архива привязки        |

Также необходимо наличие файла `README.md`, в котором дано описание
языковой привязки.

Любые другие цели, параметры, структура проекта и прочее, оставляется
на ваше усмотрение, но указанные цели должны быть объявлены и реализованы.

## Генерация файлов привязки

Для создания языковой привязки к любой библиотеке, написанной на C или
другом языке, нужно для каждой функции и символов в библиотеке подготовить
код на вашем языке.

В `libBeresta` информация о функциях библиотеки вынесена в отдельные файлы
генератора (в форматах S-выражений, YAML или JSON), поэтому возможна
создание привязок в автоматическом или полуавтоматическом режиме.

См. [README_ru.md][gen_readme] и
[https://github.com/libBeresta/libBeresta/blob/master/gen/][gen].

## Процесс

Если хотите создать языковую привязку, начните с создания PR в этом
репозитории.

На основе PR мы создадим репозиторий в огранизации [libBeresta][org]
и перенесем содержимое вашего PR в репозиторий, чтобы вы могли продолжить
работу там.
